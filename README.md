# ZPPS SRP Camp Solapur - School Website

A modern, mobile-first website for Zilla Parishad Primary School SRP Camp, Solapur North, Maharashtra.

## 🎓 Features

- **Multilingual Support** - Marathi (मराठी) & English
- **Mobile-First Design** - Optimized for smartphones
- **Admin Dashboard** - Easy content management
- **Image Upload** - Direct uploads to Supabase Storage
- **Admission Form** - Online admission applications
- **Contact Form** - Direct inquiries
- **Notice Board** - School announcements
- **PWA Ready** - Install as app on mobile devices

## 🚀 Tech Stack

- **Frontend:** React 19 + TypeScript + Vite
- **Styling:** TailwindCSS 4
- **Backend:** Supabase (Database + Auth + Storage)
- **Icons:** Lucide React
- **Deployment:** Vercel

## 📱 For Parents & Students

- Browse in Marathi or English
- View notices and announcements
- Check school facilities
- Submit admission applications
- Contact school directly

## 👨‍💼 For School Admin

- Manage notices and highlights
- Review admission applications
- Upload school photos
- Update school information
- View contact inquiries

## 🛠️ Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Type check
npm run lint
```

## 🌐 Environment Variables

Create a `.env` file with:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## 📦 Deployment

This project is configured for Vercel deployment:

1. Push code to GitHub
2. Import project in Vercel
3. Add environment variables in Vercel dashboard
4. Deploy!

## 🗄️ Database Setup

1. Create Supabase project
2. Run SQL schema from `supabase_setup.sql`
3. Create storage bucket named `school-images`
4. Create admin user in Supabase Authentication
